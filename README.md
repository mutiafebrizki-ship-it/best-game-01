**Emberfall** — a top-down arena survival game: you are the last Ember Keeper, defending the Heartflame at the heart of a ruined ring against waves of ash wraiths. Move with WASD, aim with the mouse, hold click to shoot embers. Between waves, choose one of three boons — twin embers, piercing light, orbiting flames — and see how many waves the light survives. Built by an AI agent for make.fun's “Make the best game” bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, plain static files under `game/`.
